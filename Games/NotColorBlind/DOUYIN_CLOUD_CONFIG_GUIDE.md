# 抖音云数据库配置指南

## 错误21102解决方案

错误码 `21102` 通常表示"权限不足或集合不存在"。

### 解决方案步骤

#### 1. 检查环境ID
- 确认环境ID `env-nJ2KymQ8pn` 在抖音云控制台中存在
- 环境ID格式通常为 `env-xxxxxxxxxx`

#### 2. 创建集合
在抖音云控制台中创建集合：
- 集合名称：`game_progress`
- 字段类型：
  ```json
  {
    "user_id": "string",
    "username": "string",
    "avatar_url": "string",
    "max_level": "number",
    "busy_coins": "number",
    "update_time": "string"
  }
  ```

#### 3. 设置权限
确保应用有以下权限：
- 云数据库读权限
- 云数据库写权限
- 集合访问权限

#### 4. 验证配置
- 应用ID正确
- 应用密钥正确
- 环境ID正确

### 调试信息

运行游戏时，控制台会显示：
```
=== 抖音云数据库配置信息 ===
环境ID: env-nJ2KymQ8pn
集合名称: game_progress
平台支持: True
已初始化: True
```

### 常见错误码

- `21101`: 集合不存在
- `21102`: 权限不足或集合不存在
- `21103`: 数据格式错误
- `21104`: 网络连接错误
- `21105`: 参数错误
- `21106`: 服务不可用

### 降级方案

如果云数据库不可用，系统会自动使用本地存储（TTStorage）作为降级方案。
